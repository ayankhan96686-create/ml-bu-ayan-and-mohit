# 03_Processed_Data

This directory is intentionally left empty for this phase of the research project.

## Research Phase Protocol

In accordance with the project data governance rules:
- **Phase 1 (Current Phase)**: Data discovery, acquisition, organization, integrity checking, and verification. No model training, preprocessing pipelines, or data cleaning transformations are performed in this phase.
- **Phase 2 (Subsequent Phase)**: Spatial harmonization, raster regridding, county zonal averaging, feature engineering, missing-value treatment, and model training dataset compilation will take place in this directory.

All raw observations and original archives remain preserved in `../01_Raw_Data/` and `../02_Extracted_Data/`.
